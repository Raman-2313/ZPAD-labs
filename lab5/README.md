## Опис проєкту

Метою роботи є створення інтерактивного веб-додатка на базі бібліотеки **Streamlit** для візуалізації та аналізу екологічних індексів (VCI, TCI, VHI) в Україні. Додаток використовує очищені дані, отримані в ході Лабораторної роботи №2 з серверів NOAA.

## Функціональні можливості
Програма реалізована з використанням двоколонкового макету:
- **Панель керування (ліва колонка):**
    - Вибір індексу (VCI, TCI, VHI) через випадаючий список.
    - Вибір області України (індексація за українською абеткою).
    - Фільтрація даних за допомогою слайдерів (діапазон років та тижнів).
    - Чекбокси для сортування таблиці (з автоматичним пріоритетом при виборі обох варіантів).
    - Кнопка **"Скинути налаштування"**, що повертає інтерфейс до початкового стану.
- **Візуалізація (права колонка):**
    - **Таблиця:** перегляд відфільтрованих та відсортованих даних.
    - **Графік області:** інтерактивна лінійна діаграма динаміки показника.
    - **Порівняння:** порівняльний аналіз обраної області з іншими регіонами України.
