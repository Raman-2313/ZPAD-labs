# Лабораторна робота №6: C++ openCV

Опис: Програма на C++ для захоплення відео з вебкамери в реальному часі, реалізована за модульним принципом. Підтримує динамічне перемикання ефектів обробки зображення за допомогою клавіатури.

## Модульна структура проєкту
* `CameraProvider` — модуль захоплення та ініціалізації відеопотоку.
* `Display` — модуль створення вікна та виведення зображення.
* `KeyProcessor` — обробник натискань клавіш та керування режимами.
* `FrameProcessor` — конвеєр застосування фільтрів OpenCV до кадрів.

## Вимоги до системи
* Операційна система: Linux (Ubuntu / Debian)
* Встановлені утиліти: CMake (3.10+), GCC/G++ (з підтримкою C++17), OpenCV 4.x

## Інструкція з білду та запуску

Скрипти автоматизації дозволяють підготувати та запустити проєкт у декілька команд. Перед першим запуском підготуйте скрипти (зробіть файли виконуваними):
```bash
chmod +x *.sh
```
1. Підготовка оточення (інсталяція залежностей): `./preinstall.sh`
2. Компіляція проекту: `./build.sh`
3. Запуск програми: `./run.sh`
